# Certificaciones

Esta carpeta es opcional. Si tienes certificaciones de Databricks (Data Engineer Associate, Databricks Lakehouse Fundamentals, etc.) o de Azure (AZ-900, DP-203), agrega los PNGs aquí junto con los enlaces verificables.

## Estructura sugerida

```
certificaciones/
├── databricks_data_engineer_associate.png
├── databricks_lakehouse_fundamentals.png
├── az_900.png
└── enlaces.txt
```
